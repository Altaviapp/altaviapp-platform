# PWA Icons Required

Please add the following icon files to this directory:

## Required Files:
- `favicon.ico` - 16x16 or 32x32 favicon
- `icon-192x192.png` - 192x192 PNG icon for PWA
- `icon-512x512.png` - 512x512 PNG icon for PWA

## Recommended Tools:
- Use https://realfavicongenerator.net/ to generate all required icons
- Or use https://www.favicon-generator.org/

## Icon Design Guidelines:
- Simple, recognizable logo
- High contrast for visibility
- School bus or transport-related imagery
- Brand colors from Altaviapp
