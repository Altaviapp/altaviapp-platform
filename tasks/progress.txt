## Codebase Patterns
- Bulk route wizard uses step-based state management in BulkRouteWizard.tsx
- Step components should be in apps/admin/src/components/routes/bulk-wizard/
- WizardStepIndicator handles step navigation and progress display
- Spanish is the primary language for UI labels (Ecuador/Colombia localization)
- Form validation uses react-hook-form + Zod patterns
- Step components receive `data`, `onChange`, and `onValidChange` props
- useInstitution hook provides school location for validation
- Use useConvexAuth hook for typed userId/institutionId in admin app
- Import api from '../../../../../../convex/_generated/api' (relative path) in admin components
